Le contenu principal, les titres, les textes, les coordonnées et les liens doivent être présents dans le HTML initial.

Mettre en place, selon les possibilités de Figma Sites :
- rendu HTML statique ;
- prérendu ;
- rendu côté serveur ;
- ou toute solution permettant à Googlebot de lire immédiatement le contenu.

Le site doit rester utilisable avec JavaScript, mais le contenu essentiel ne doit pas dépendre exclusivement de JavaScript.
